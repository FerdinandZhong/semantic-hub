Semantic context and query evidence

power_measured_import · sample r1

One reading per meter and half-hour interval. Imported energy uses kWh. UTC timestamps map to Singapore reporting dates.

Missing and estimated readings are excluded. This page displays prepared results; it does not execute SQL.

Inspect illustrative daily-total SQL
SELECT reading_date, SUM(import_kwh) AS measured_import_kwh, COUNT(*) AS valid_readings
FROM iceberg.power.meter_readings
WHERE quality_status = 'VALID' AND is_estimated = 'false'
  AND reading_date BETWEEN DATE '2026-09-24' AND DATE '2026-09-30'
GROUP BY reading_date ORDER BY reading_date
